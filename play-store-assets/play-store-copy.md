# Menu Matrix - Google Play Store Copy

## Short Description
Restaurant menu training with allergens, ingredients, flash cards, and quizzes.

## Long Description
Menu Matrix helps restaurants turn menu knowledge into an easy training experience for servers, managers, and new team members.

Build restaurant menus with dish names, prices, descriptions, ingredients, allergens, photos, portions, and service notes. Team members can browse the menu, open each item for more detail, filter by allergens or ingredients, and study with built-in flash cards and randomized quizzes.

The app is designed for restaurant training, menu learning, and daily pre-shift practice. Admins can create and manage menus, customize the app theme, upload item photos, import menu information, manage categories, and control user access. Menus can also be shared with viewers using access codes, so staff or testers can view training menus without needing full editing access.

Key features:
- Create training menus for restaurants
- Add prices, descriptions, allergens, ingredients, and notes
- Upload multiple photos per menu item
- Filter dishes by allergy or ingredient
- Practice menu knowledge with flash cards
- Take randomized quizzes and save quiz results
- Share menus with access codes
- Manage users and editing permissions
- Customize colors, logo/banner media, and item image size
- Import menu information from PDFs or scanned menu photos

Menu Matrix is built for restaurants that want a cleaner way to train staff, keep menu details organized, and help teams answer guest questions with confidence.
